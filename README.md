# 🧠 بازی Memory Match

یک بازی حافظه با زبان پایتون، رابط گرافیکی Tkinter و تصاویر اختصاصی کارت‌ها.

در این پروژه، فایل `game_logic.py` منطق و قوانین بازی را از رابط گرافیکی جدا می‌کند تا بتوانیم قوانین بازی را بدون باز کردن پنجرهٔ بازی آزمایش کنیم.

## 📂 ساختار فایل‌های پروژه

```text
memory_match_unittest_v2/
├── main.py
├── game_logic.py
├── README.md
├── test_results.txt
├── assets/
│   └── cards/
│       └── تصاویر کارت‌ها
└── tests/
    ├── __init__.py
    └── test_game_logic.py
```

## 🎮 اجرای بازی

ابتدا پوشهٔ پروژه را در Visual Studio Code باز کنید و سپس دستور زیر را در ترمینال اجرا کنید:

```bash
python main.py
```

## 🧪 اجرای تست‌ها

برای اجرای تست‌های خودکار، از مسیر اصلی پروژه دستور زیر را در ترمینال وارد کنید:

```bash
python -m unittest discover -s tests -v
```

این پروژه شامل چهار تست خودکار است که موارد زیر را بررسی می‌کنند:

1. اضافه‌شدن امتیاز پس از پاسخ صحیح.
2. افزایش سطح بازی پس از چهار پاسخ صحیح متوالی.
3. مدیریت پاسخ اشتباه و بازنشانی پیشرفت.
4. جابه‌جایی صحیح کارت‌ها پس از هر پاسخ.

کتابخانهٔ `unittest` به‌صورت پیش‌فرض همراه پایتون ارائه می‌شود؛ بنابراین برای اجرای تست‌ها نیازی به نصب کتابخانهٔ جداگانه‌ای نیست.

## 🛠️ فناوری‌های استفاده‌شده

- **Python:** زبان برنامه‌نویسی پروژه
- **Tkinter:** ساخت رابط گرافیکی
- **OOP:** استفاده از برنامه‌نویسی شیءگرا
- **unittest:** آزمایش خودکار منطق بازی
